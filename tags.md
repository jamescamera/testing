# Tag vocabulary

A controlled list, kept deliberately small. Tag sprawl is what kills an
archive like this: fifty one-use tags filter nothing and connect nothing.

**Rule:** prefer an existing tag. Only add a new one when a page genuinely
does not fit any of these *and* the idea is likely to recur. When you add
one, add it here in the same commit with a one-line definition.

## Idea type

| tag | use for |
| --- | --- |
| `claim` | a specific product claim, number, or proof point |
| `territory` | a broad emotional or strategic space the work could live in |
| `line` | a candidate headline, tagline, or piece of copy |
| `naming` | product, brand, platform, or campaign name candidates |
| `visual` | a visual device, art direction, or sketched image idea |
| `structure` | how a piece is built - format, sequence, mechanic |

## Subject matter

| tag | use for |
| --- | --- |
| `delivery-system` | how a treatment reaches the patient |
| `device-concept` | the physical object itself |
| `dosing-frequency` | how often, how many doses, schedule |
| `procedure-time` | duration of a procedure or intervention |
| `materials` | what something is made of |
| `patient-experience` | what it is like to be on the receiving end |
| `clinician` | the prescriber, surgeon, or nurse's side |
| `competitor` | a named or implied rival |
| `regulatory` | approvals, labelling, restrictions |

## Status

| tag | use for |
| --- | --- |
| `unresolved` | the page poses a question it does not answer |
| `revisit` | flagged as worth coming back to |
